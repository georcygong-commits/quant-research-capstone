量化全流程学习路径
主线：多因子选股量化研究员 ｜ 方法：每个阶段做一个可交付项目，沉淀 GitHub 作品集 ｜ 你已完成阶段 0 的数据工程。
阶段 0 · 已完成
工具与数据地基
学：Python(pandas/numpy)、SQL、Git、Linux 命令行；股票/期货/期权交易规则、复权、财报口径
项目：Wind→Qlib 全 A 分钟数据工程（已完成：拉取/清洗/对齐/增量）
阶段 1 · 最核心
单因子研究全流程（约 3-4 周）
学：因子分类（量价/基本面/另类）；预处理（去极值、标准化、缺失）；IC/IR、分层回测、换手率、因子衰减；行业/市值中性化
项目：手工实现 30-50 个经典因子（动量、反转、波动率、流动性、换手率、市值、估值），产出完整因子分析报告（alphalens / jqfactor_analyzer）
验收：能讲清一个因子为何有效、IC 多少、怎么中性化、何时失效
阶段 2
多因子合成与选股模型（约 3 周）
学：因子合成（等权/IC 加权/最大化 ICIR）；多因子模型；机器学习选股（LightGBM）；滚动交叉验证、防过拟合、特征重要性
项目：Qlib 跑 Alpha158 + LightGBM，对比线性合成 vs 机器学习，做样本外滚动预测
验收：能讲清过拟合来源、为何滚动验证、ML 相比线性的优劣
阶段 3
组合构建 · 风险模型 · 回测归因（约 3-4 周）
学：组合优化（均值方差、风险平价、行业/风格/换手约束）；Barra 风险模型；交易成本与滑点；增强指数；绩效归因（Brinson、因子归因）
项目：端到端选股策略：预测信号 → 目标持仓（带约束）→ 完整回测 → 归因报告
验收：能解释收益来源、风险暴露、策略容量
阶段 4 · 差异化
因子挖掘进阶（约 4 周）
学：遗传规划/符号回归；强化学习挖因子（AlphaGen）；深度学习因子（LSTM/Transformer/GAT）；另类数据；LLM 挖因子（RD-Agent）
项目：复现 AlphaGen 或 Alpha101，自动挖一批因子并评估，复现一篇论文
验收：理解前沿方法边界，能独立复现论文
阶段 5 · 可选
实盘工程化 / 高频拓展
实盘方向：QMT/vnpy 对接，模拟盘/小资金实盘，记录实盘 vs 回测，理解冲击成本与实盘坑
高频方向：补 C++、Level2 逐笔与微观结构、日内因子（门槛不同，按求职目标决定）
求职准备（贯穿全程）
作品集（3-4 个）：数据工程、单因子研究、多因子选股模型、自动因子挖掘；放 GitHub，README 写清数据与结论
面试考点：概率统计与 brain teaser、因子理解、回测细节、代码题（Python/算法）、金融常识、市场感觉
关键动作：争取一段量化实习（上海机会多）；简历用真实数据与可量化结果；多复盘、记录每次失效
建议：少看教程、多做完整项目；每个阶段都要能「讲给别人听」。岗位方向可在做完阶段 1-3 后再细化。
